# suhree 디자인 고도화 제안

작성일: 2026-10-15 · 현재 소스 v0.4.9 기준 · 포근한 농장 적용

사용자 선택: ‘포근한 농장’ 방향으로 실제 UI를 구현하고 여행 기능을 제거한다.

## 목표

작업하는 화면 아래에 작은 농장이 살아 있는 느낌을 유지하면서, 씨앗 선택과 친구 서리까지의 흐름을 쉽게 만든다. 도트 작물은 주인공으로 남기고, 메뉴와 패널은 읽기 쉬운 보조 도구로 정돈한다.

현재 구현을 소스로 검토한 제안이며 사용자 테스트 결과는 아니다. 목업의 닉네임·잔액·친구 상태는 예시다. 작물 가격과 성장 시간은 현재 balance.ts 값을 사용하고, 판매가는 시세 배율 1.0의 기본값으로 표시한다.

## 현재 관찰과 개선 방향

| 현재 구현 | 개선 방향 | 기대 효과 |
| --- | --- | --- |
| 일반 HUD에 씨앗부터 설정까지 12개 메뉴가 한 줄에 배치됨 | 씨앗·친구·마을·더보기의 4개 진입점으로 묶기 | 가장 자주 하는 행동을 빠르게 찾음 |

| 모든 글자에 도트 폰트 적용 | 브랜드·짧은 제목은 MulmaruMono, 설명·숫자는 가독성 좋은 시스템 글꼴 | 작은 패널에서도 조건과 시간을 쉽게 읽음 |

| 친구 상태가 작은 점과 버튼 문구로 표현됨 | 온라인·오프라인·대기 시간을 텍스트로 함께 표시 | 색상 없이도 서리 가능 여부를 이해함 |
| 캔버스 HUD 및 투명 오버레이 사용 | 키보드 접근 가능한 DOM 메뉴와 실제 표시 영역의 hit region 동기화 검토 | 접근성 개선과 바탕화면 클릭통과 유지 |

근거: src/render/strip.ts의 HUD_LABELS·hudLayout, src/styles.css의 #panel·.card·.btn, src/render/panels.ts의 shopPanel·friendsPanel·positionPanel, src/config/balance.ts의 strip·crops.

## 추천안: 포근한 농장

따뜻한 종이색 패널, 짙은 잎색 주요 버튼, 얇은 갈색 구분선, 기존 작물 스프라이트를 사용한다. 메뉴를 열면 농장 바로 위에 380px 안팎의 패널이 나타나며, 닫으면 얇은 작물 띠가 남는다. 밝고 어두운 시스템 모드 모두 같은 따뜻한 인상을 유지한다.

대안인 **컴팩트 도크**는 씨앗을 가로로 고르는 넓고 낮은 트레이를 사용한다. 세로 공간은 절약되지만 가로 폭이 더 필요하다. 작은 모니터나 창 경계에서는 세로 패널로 접힌다.

## 정보 구조

| HUD 진입점 | 내부 항목 |
| --- | --- |
| 씨앗 | 일반·스페셜 씨앗, 선택 씨앗, 심기 비용, 성장 시간, 현재 수확가 |
| 친구 | 친구 목록, 친구코드 추가, 온라인 상태, 서리 가능·대기 상태 |
| 마을 | 채팅, 낙서장, 서리기록 |
| 더보기 | 상점의 강화·밭 확장, 꾸미기, 도감, 랭킹, 통계, 설정 |

기존 씨앗과 상점의 씨앗 목록 진입은 하나로 합친다. 숨겨진 점지 메뉴는 기존 노출 조건을 유지한다. 여행 기능을 제거하고 나머지 메뉴의 탐색 구조를 재배치한다.

## 핵심 화면과 상태

1. **평상시**: 기존 48 논리 px 밭 영역을 기준으로 얇은 흙선과 작물만 표시. 기본 상태에서 바탕화면을 가리는 상시 카드나 큰 배경을 추가하지 않는다.
2. **메뉴 펼침**: 잔액과 4개 진입점. 포인터가 메뉴에서 패널로 이동하는 동안 열림을 유지하고, 키보드 포커스가 있으면 자동으로 닫지 않는다.
3. **씨앗**: 선택 체크, 비용, 성장 시간, 기본/현재 수확가를 같은 위치에 표시. 씨앗 선택은 무료이며 빈 밭을 눌러 심을 때 비용을 차감한다. 잔액 부족·잠금 조건은 텍스트로 보여준다.
4. **친구**: 온라인 친구 우선. 가능한 행동은 ‘서리하기’, 불가능한 상태는 ‘오프라인’·‘대기 2:18’처럼 이유를 표시한다. 온라인 여부만으로 실제 서리 성공을 보장하지 않으며 기존 잠금 검증을 유지한다.
5. **서리 진행**: 평상시 녹색 계열과 구별되는 경고색, 남은 시간, 획득 코인, 도망치기. 방어 시에는 침입자 커서를 눌러 쫓아내야 한다는 행동을 짧게 안내한다.
6. **완료·빈 상태·오류**: 수확 피드백, 친구 없음, 연결 끊김, 잠긴 씨앗, 쿨다운, 재접속 중 화면을 함께 설계한다.

## 시각 규칙

- 색상: 종이·흙·잎·금색의 제한된 팔레트. 서리 위험과 오류만 경고색 사용. 상태는 항상 글자나 아이콘을 함께 표시한다.
- 글자: 제목 18~22px, 본문 13~14px, 보조 정보 최소 12px. 코인과 시간은 숫자 폭을 고정한다.
- 공간: 4px 단위 간격, 패널 안쪽 16~20px, 버튼 높이 36px 이상. 터치 환경은 44px 목표.
- 형태: 패널 모서리 16px 안팎, 카드 10px, 버튼 8px. 두꺼운 겹테두리와 큰 그림자를 줄인다.
- 픽셀아트: 원본 그리드와 팔레트를 재사용하고 정수 배율로 표시한다. 설명과 입력 영역까지 도트 글꼴을 확장하지 않는다.
- 움직임: 메뉴 열기와 수확 피드백 중심의 짧은 전환. 모션 감소 설정에서는 이동 효과를 줄인다.

## 검증

- Windows 100%·125%·150% 배율, 다중 모니터, 상단/하단 도킹에서 패널이 화면 밖으로 나가지 않는지 확인한다.
- 패널 바깥 클릭통과, 메뉴→패널 포인터 이동, Escape 닫기, 닫은 뒤 포커스 복귀를 검증한다.
- 키보드만으로 씨앗 선택과 메뉴 이동이 가능하며 포커스 표시가 보이는지 확인한다.
- 긴 닉네임, 큰 코인 값, 잔액 부족, 잠금, 오프라인, 쿨다운, 네트워크 오류를 확인한다.
- 메뉴 개편 후 처음 사용하는 사람이 씨앗을 고르고 심기, 친구 서리 가능 여부 찾기를 설명 없이 수행할 수 있는지 관찰한다.
- 이번 목업은 로컬 화면 전환·씨앗 선택·심기·수확·서리 상태 예시를 제공한다. 실제 멀티플레이, 시간 경과 성장, 결제, 운영 데이터 연결은 포함하지 않는다.

## 이번 제안의 범위

실제 UI에 공통 색상·글꼴·간격, 키보드 접근 가능한 4개 메뉴, 씨앗 선택과 강화 상점 분리, 친구 상태 구분을 적용했다. 채팅 입력은 데이터 갱신 시 DOM을 유지한다. 메뉴·패널만 클릭 영역에 등록하고, 패널을 위한 투명 창 높이를 최대 640 논리 px로 조정했다. 작은 화면에서는 운영체제 작업 영역에 맞춰 제한한다.

여행 전용 HTML·엔진·동기화 코드·페이로드·네이티브 명령·권한·빌드 항목과 로컬 DB 규칙을 제거했다. 원격 규칙 배포나 운영 데이터 삭제는 이번 로컬 구현 범위에 포함하지 않는다.

P2의 추가 수확 연출과 사운드 개편은 후속 작업이다. 기존 작물과 서리 연출은 유지하고, 메뉴 전환은 모션 감소 설정을 따른다.

검증 결과: TypeScript + Vite 프로덕션 빌드, Rust `cargo check`, 변경분 공백 검사와 DB 규칙 JSON 구문 검사를 통과했다. 오프라인 UI에서 1024×640 및 360×480 배치, 상단 도킹, 씨앗 선택 유지, 긴 목록 스크롤, 코인 부족·잠금 상태, 친구 상태, 하위 메뉴 왕복, 채팅 초안 보존, F2·Enter·Escape를 확인했다. Windows 네이티브 창의 실제 클릭통과와 여러 모니터/DPI 조합은 별도 실행 검증 대상이다.
